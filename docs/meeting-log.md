- **스니펫 조립 방식 확인**: 검색 단위는 함수/클래스 단위, BM25 점수 상위 3개 선택, 정답 파일 강제 포함 없음, 배치 순서는 BM25 점수 순 그대로임을 재확인. 기존 두 조립 방식(옛/새)을 본표에 모두 유지하고 LlamaIndex는 보조표로 두는 구성에 대해 교수님께 확인. 검색 순서 고정(정렬)을 기본 처방으로 승격할지 질문함.

- **속도·품질 재측정 방식**: 기존 데이터를 재사용하는 안(편리하나 모양새 불리)과 새로 추출한 문제로 속도를 재측정하는 안(속도·품질 표본 수 일치) 중 논의.

- **실험 버전 게재 범위**: 최종 보고서에 수정 전 실험 과정을 모두 실을지, 최종 확정 버전만 실을지 문의. 실제 운영 상황과 더 유사한 방식이 무엇인지도 함께 질문.
